# Gazebo 树冠绕行程序控制逻辑

本文档对应当前版本的：

- `launch/gazebo_canopy_sim.launch`
- `src/odom_listener_5_dipan.cpp`
- `urdf/tracked_canopy_robot.urdf.xacro`

完整流程图见 [gazebo_canopy_control_flow.svg](gazebo_canopy_control_flow.svg)。

## 1. 系统闭环

Gazebo 中的车辆采用平面运动插件，不模拟履带与地面的真实摩擦和滑移。插件接收 `/cmd_vel`，直接更新车辆的平面位置和航向，同时发布 `/Odometry`。

右侧 MID-360 仿真雷达安装在车体右边缘，朝车体右侧，发布 `/scan_2d`。控制节点 `odom_listener_5_dipan` 根据里程计和雷达点云计算下一帧速度，再发布回 `/cmd_vel`，形成闭环：

```text
Gazebo 车辆和树冠
    ├─ /Odometry ──> 位置、航向、绕行进度
    └─ /scan_2d  ──> 树冠局部轮廓、距离、作业面朝向
                         │
                         v
              odom_listener_5_dipan
                         │
                         └─ /cmd_vel ──> Gazebo 平面运动插件
```

雷达扫描为 360°、1800 点、10 Hz，距离范围为 `0.10～50.00 m`。蓝色激光射线默认不在 Gazebo 中显示，但 `/scan_2d` 始终正常发布。

## 2. 坐标与“正对树冠”的定义

- `base_link.x`：小车前进方向。
- `base_link.y`：小车左侧。
- 雷达安装偏航为 `-90°`，因此 `livox_frame.x` 指向小车右侧，也就是树冠方向。
- `livox_frame.y` 对应小车前后方向。
- 右侧作业面沿小车前后方向布置，有效长度为 `1.0 m`。

程序中的“正对树冠”不是车头朝向树冠，而是同时满足：

1. 右侧作业面与局部树冠切线平行，即树冠拟合线在雷达坐标系中接近 `±90°`；
2. 雷达法向指向局部树冠，即树冠点集质心方位接近 `0°`。

## 3. 里程计处理与绕行进度

节点第一次收到有效 `/Odometry` 时：

1. 记录当前位置为整圈起点；
2. 记录当前位置为第一移动分段的起点；
3. 不要求 Fast-LIO 或 Gazebo 的数值原点必须是 `(0, 0)`。

首次得到有效树冠拟合后，程序利用雷达表面距离、质心方位和设定树冠半径估计树心。当前 launch 中 `lock_tree_estimate=true`，因此树心第一次确定后保持固定。

后续每一帧里程计都计算车辆相对固定树心的极角变化：

```text
delta = normalize(current_orbit_angle - last_orbit_angle)
accumulated_orbit_angle += delta
```

正向和反向变化都会累计，因此车辆在同一区域往返抖动时增量可以互相抵消。若单帧极角变化超过 `15°`，视为里程计跳变，该帧不累计。

顺时针时完成进度为 `-accumulated_orbit_angle`，逆时针时为 `+accumulated_orbit_angle`。

## 4. 每帧雷达数据处理

### 4.1 两个 ROI

当前 launch 使用两个有重叠的雷达区域：

| 区域 | 默认角度 | 用途 |
|---|---:|---|
| 航向 ROI | `-30°～120°` | 拟合下一步绕树移动所需的局部树冠切线 |
| 正对 ROI | `-45°～45°` | 计算右侧距离并判断作业面是否与局部树冠平行 |

所有点首先必须满足 LaserScan 自身的 `range_min` 和 `range_max`。

### 4.2 航向 ROI 拟合

航向 ROI 使用 PCA 拟合局部直线。PCA 直线有 180° 二义性，程序选择与当前车辆前进方向一致的分支；如果 PCA 主轴实际沿树冠弧面的深度方向，则在主轴和垂线之间选择更接近车辆前进方向的一条。

移动时还会对航向进行：

- 180° 分支连续性处理；
- 单帧最大 `5°` 变化限幅；
- 默认 5 帧圆周角滑动平均。

### 4.3 右侧作业面拟合

正对 ROI 使用确定性的两阶段 PCA：

1. 取 ROI 距离的第 5 百分位作为稳健最近树冠距离；
2. 只保留该距离前 `0.05 m` 到其后 `0.4 m` 深度带内的点；
3. 只保留雷达横向 `±0.5 m` 内的点，对应 `1.0 m` 作业面长度；
4. 第一次 PCA 拟合局部表面；
5. 根据正交残差的中位数和 MAD 剔除离群点；
6. 对内点执行第二次 PCA；
7. 同时满足以下条件才认为拟合有效：
   - 内点不少于 `20`；
   - 横向覆盖不少于 `0.4 m`；
   - RMS 正交残差不大于 `0.08 m`；
   - PCA 主次特征值比不小于 `4.0`。

只要正常运行状态下作业面拟合无效，程序立即发布零速度、保持当前状态，并清空正对稳定计时。

## 5. 状态机

状态机包含五个状态：

### 5.1 `WORK_PAUSE`：作业停顿

- 持续发布零速度；
- 默认停顿 `1.0 s`；
- 时间到后进入 `ALIGN_TANGENT`。

节点启动后的初始状态也是 `WORK_PAUSE`。

### 5.2 `ALIGN_TANGENT`：移动前对准

该状态复用作业面正对控制：

- 表面线误差要求不超过 `2°`；
- 质心方位误差要求不超过 `5°`；
- 两个条件必须连续满足 `0.4 s`；
- 任一帧超限或拟合失效，稳定计时立即清零。

尚未对准时，小车原地转向：

```text
linear.x = 0
fused_error = 0.85 × line_error + 0.15 × bearing_error
angular.z = clamp(0.8 × fused_error, -0.12, 0.12)
```

如果仍未对准但计算出的角速度过小，则至少输出 `0.02 rad/s`。连续稳定完成后，记录新的分段起点、清空航向滤波历史并进入 `MOVE_AROUND_CANOPY`。

### 5.3 `MOVE_AROUND_CANOPY`：绕树移动

正常情况下，航向由雷达航向 ROI 的局部树冠切线主导。角速度由四部分组成：

```text
angular.z = 绕行方向前馈
          + 局部切线航向修正
          + 树冠质心方位修正
          + 右侧表面距离修正
```

- 前馈项决定顺时针或逆时针以及大致绕行曲率；
- 航向项使车辆沿雷达拟合出的局部树冠切线前进；
- 方位项让树冠保持在右侧雷达法向附近；
- 距离项在移动过程中把雷达到树冠表面的距离保持在目标值附近。

当距离误差超过容差时，航向项和方位项缩小到原来的 `35%`，提高距离修正的优先级。线速度会随航向、方位和距离误差增大而降低，但仍保留最低速度比例，避免退化为持续原地旋转。

如果航向 ROI 暂时无效：

- 最多 `0.5 s` 使用固定树心的几何切线兜底；
- 超过 `0.5 s` 仍无有效局部轮廓则停车；
- 正对 ROI 无效时不使用兜底，而是立即停车。

每个分段的目标里程是 `0.50 m`。达到目标里程后还要检查右侧树冠距离：

- 距离位于 `0.50±0.05 m`：停车并进入 `FACE_CANOPY`；
- 距离不在该范围：继续向前移动，同时调整与树冠的距离。

### 5.4 `FACE_CANOPY`：正对树冠调整

移动分段完成后，再次调用与 `ALIGN_TANGENT` 完全相同的作业面正对控制：

- `linear.x=0`，车辆原地转向；
- 表面线误差不超过 `2°`；
- 质心方位误差不超过 `5°`；
- 连续稳定 `0.4 s` 后进入 `WORK_PAUSE`。

于是正常循环为：

```text
作业停顿 → 移动前对准 → 绕树移动 → 正对树冠调整 → 作业停顿
```

### 5.5 `STOPPED`：完成一圈

完成一圈必须同时满足：

1. 按设定方向的净累计绕行角度达到 `360°`；
2. 当前里程计位置到启动起点的直线距离不大于 `0.50 m`。

只有角度达到 `360°`、但尚未回到起点附近时，程序不会停止，而会继续执行当前状态机循环。两个条件同时满足后进入 `STOPPED`，持续发布零速度。

## 6. 全局安全逻辑

- 尚未收到里程计：停车等待。
- 两个雷达 ROI 都没有足够点且超过扫描超时：停车。
- 作业面拟合质量不合格：立即停车并保持当前状态。
- 航向 ROI 短时无效：几何切线兜底最多 `0.5 s`。
- 航向 ROI 持续无效：停车。
- 尚未建立树心估计：禁止进入绕树移动。
- 节点退出：析构函数再发布一次零速度。

## 7. 默认关键参数

| 参数 | 当前值 | 含义 |
|---|---:|---|
| `clockwise` | `true` | 顺时针绕树 |
| `step_distance` | `0.50 m` | 单段基础移动距离 |
| `target_distance` | `0.50 m` | 雷达到树冠表面的移动目标距离 |
| `distance_tolerance` | `0.05 m` | 分段结束允许的距离误差 |
| `linear_speed` | `0.10 m/s` | 基础线速度 |
| `max_angular_speed` | `0.12 rad/s` | 最大角速度 |
| `work_pause_duration` | `1.0 s` | 每个作业点停顿时间 |
| `align_tolerance_deg` | `2°` | 作业面与树冠切线最大夹角 |
| `facing_bearing_tolerance_deg` | `5°` | 树冠质心最大方位误差 |
| `facing_stable_duration` | `0.4 s` | 正对条件连续稳定时间 |
| `return_distance_threshold` | `0.50 m` | 完成一圈时允许的返航距离 |
| `canopy_radius_for_orbit` | `2.75 m` | 初始树心估计使用的近似半径 |

这些 Gazebo 默认值集中在 `launch/gazebo_canopy_sim.launch` 中修改。
